CLEANCONNECT - Flask starter

1. Open a terminal in this folder.
2. Create/activate your virtual environment:
   python -m venv venv
   venv\Scripts\activate
3. Install Flask:
   pip install flask
4. Run:
   python app.py
5. Open:
   http://127.0.0.1:5000

The project uses local SVG illustrations so it works immediately without external image links.
Replace the SVG files in static/images with real cleanup photographs later.
